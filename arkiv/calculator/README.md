Advanced Calculator

Quick start

- Open [index.html](index.html) in your browser.
- Type mathematical expressions in the input and press `Evaluate` or Enter.
- Supported: trigonometric functions, complex numbers (e.g. `2+3i`), matrices, units and more via math.js.
- Toggle between radians and degrees with the `RAD`/`DEG` button.

Examples

- `sin(pi/4)*sqrt(2)`
- `factorial(10)`
- `det([[1,2],[3,4]])`
